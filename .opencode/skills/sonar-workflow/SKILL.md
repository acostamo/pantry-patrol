# SonarCloud workflow

Project: `acostamo_pantry-patrol` · Org: `acostamo` · CI step in `.github/workflows/main.yml` (needs `SONAR_TOKEN` secret). SonarCloud **Automatic Analysis must be OFF** for the project, otherwise CI fails with "You are running CI analysis while Automatic Analysis is enabled".

## Analysis scope (sonar-project.properties)

- `sonar.sources=src` only — android/ios/www/node_modules are excluded and NOT analyzed by CI.
- **Do not remove `src/assets/**` from exclusions.** It contains binary PNG/WebP files; analyzing them triggers the "problems with file encoding" warning.
- Coverage from `coverage/app/lcov.info`; new-code gate is **≥ 80%**.

## Triage via the API

The SonarQube MCP supports `pullRequest` on issue searches and status changes. Use the project key `acostamo_pantry-patrol` explicitly (the MCP default points elsewhere). Query open issues on a PR with `issueStatuses=["OPEN"]` + `pullRequest=N`.

## Resolution policies

- **`Web:MouseEventWithoutKeyboardEquivalentCheck` on `ion-button`/`ion-fab-button`** → **false positive**. Ionic renders native `<button>` with built-in keyboard support; adding keydown handlers would double-fire. Do NOT "fix" by adding handlers. Mark FP on the PR issue keys.
- **`Web:S6819` (`div role="button"`)** → real fix: use a native `<button type="button">` (native buttons also satisfy the keyboard rule).
- **Generated native code** — `ios/AppDelegate.swift` S1172, `ios/CapApp-SPM/Package.swift` S7694, `android/build.gradle` S8569 → mark **accepted** (won't fix; regenerated by `cap sync`).
- **`css:S4667` "Empty source"** (bug, fails reliability) → delete the empty `.scss` file and remove its `styleUrl`/`styleUrls` reference.
- **`typescript:S2245` pseudorandom** → never use `Math.random()` for security-sensitive values; use `crypto.getRandomValues` (see `randomNotificationId()`).
- **`typescript:S2699`** (test with no assertion) → add a real `expect(...)`.
- **`typescript:S5906`** → use `toHaveSize(n)` instead of `.length`.
- **`typescript:S1874` deprecated Camera API** → migrate to `takePhoto`/`chooseFromGallery` (see `capacitor-testing` skill).

## Encoding warning

"If there are problems with file encoding…" usually means a **binary file inside `sonar.sources`**. In this repo it was `src/assets/**` — already excluded. If it reappears, check the scanner log for the file list and ensure it's excluded or re-saved as UTF-8.
